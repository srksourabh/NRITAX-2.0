The statute or source reference that sits in the left margin of a ledger row, or on the edge of a money input.

```jsx
<StatuteChip>u/s 16(ia)</StatuteChip>
<StatuteChip source onClick={showExtraction}>Form 16</StatuteChip>
```

Never uppercase the reference beyond how the department writes it. Statute references are shown, not explained inline — the Explainer carries the meaning.
