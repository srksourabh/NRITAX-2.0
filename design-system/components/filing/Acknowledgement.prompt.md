The receipt after a return is filed — and the only place the stamp motion appears.

```jsx
<Acknowledgement ackNumber="284917650120726" filedOn="12 July 2026" itrForm="ITR-2"
  regime="New" figure="Refund due ₹8,557" />
```

The stamp is 180ms `cubic-bezier(0.16,1,0.3,1)`: scale 1.06 → 1, opacity 0 → 1, −1.5deg → 0. It fires once per return. Under `prefers-reduced-motion` it is a plain fade. The block keeps square corners — it is a document, not a card.
